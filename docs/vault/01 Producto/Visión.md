# Visión
Herramienta **pequeña, rápida y práctica** que un desarrollador/diseñador tiene abierta mientras trabaja.
Mezcla de color picker profesional, generador de paletas e inspector de colores para código.

**Objetivo**: definir paletas de colores útiles para interfaces y design systems.

Flujo ideal → [[Flujo principal Alt+C]].
Nombre: *matiz* = hue / nuance.
