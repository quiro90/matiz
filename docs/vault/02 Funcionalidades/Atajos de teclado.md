# Atajos de teclado
| Atajo | Acción |
|---|---|
| **Alt+C** (global, configurable) | Capturar |
| Ctrl+C | Copiar en formato principal |
| Ctrl+Shift+C | Copiar HEX |
| Ctrl+V | Pegar color o imagen |
| Ctrl+Z / Ctrl+Y | Deshacer / rehacer color |
| Ctrl+S | Agregar color actual a la paleta activa |
| Ctrl+N | Nueva paleta |
| Ctrl+O | Abrir imagen |
| Ctrl+E | Exportar paleta como PNG |
| Esc | Cerrar panel / volver al selector |

Dentro de campos de texto, Ctrl+C/V/Z actúan sobre el texto.
