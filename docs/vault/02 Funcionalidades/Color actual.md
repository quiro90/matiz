# Color actual
Panel derecho. Muestras **Anterior | Actual** (click en Anterior = volver).
- Campo principal: acepta HEX **y cualquier formato** del [[Parser de entradas]] (Enter confirma, rojo si es inválido).
- Campos R / G / B (0–255).
- Filas HEX, RGB, HSL, HSV, CMYK* con botón copiar; "Más formatos": OKLCH, CSS, ARGB, Flutter, C#.
- **Copiar todo** y **Copiar como ▾** (todos los [[Formatos de color soportados]]).
- `Ctrl+Z / Ctrl+Y` deshacen cambios confirmados ([[Fuente única de verdad]]).
