# Flujo: color desde una imagen
1. Copiar una captura (Win+Shift+S) y `Ctrl+V` en Matiz — o arrastrar un archivo.
2. Click en el píxel → color actual + [[Historial]].
3. La paleta de dominantes se **extrae sola** al cargar → pestaña "De la imagen" → agregar todo (cambiar la cantidad y "Extraer colores" para re-extraer).

Ver [[Image picker]].
