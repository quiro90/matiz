# Flujo: crear un design system
1. Capturar o escribir el color de marca ([[Color actual]]).
2. Pestaña **Escala 50–950**, prefijo `Primary` ([[Design Scale]]).
3. **Agregar todo** → paleta activa con `Primary 50…950`.
4. Repetir con secundario / acentos (otro prefijo) y **Neutros**.
5. Paleta activa → **Copiar ▾ → CSS / Tailwind / Dart / C#** ([[Exportación de código]]).
6. **PNG** para compartir ([[Exportación PNG]]).
