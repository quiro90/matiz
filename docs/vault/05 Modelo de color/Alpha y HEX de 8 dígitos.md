# Alpha y HEX de 8 dígitos
- El alpha se conserva en modelo, persistencia y formatos (ARGB, `rgba()`), pero la UI principal es opaca.
- **HEX de 8 dígitos = `#AARRGGBB`** (convención XAML / Windows / Flutter), no `#RRGGBBAA` de CSS.
- Con alpha ≠ 255 la vista previa se dibuja sobre un tablero.
