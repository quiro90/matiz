# Conversiones y redondeo
| Formato | Mostrado |
|---|---|
| HSL / HSV | grados enteros, % enteros |
| CMYK | % enteros ([[CMYK aproximado]]) |
| OKLCH | L y C con 3 decimales, h con 1 decimal (cultura invariante) |

Ejemplo `#5246BC`: RGB 82, 70, 188 · HSL 246°, 47%, 51% · HSV 246°, 63%, 74% · CMYK 56%, 63%, 0%, 26%.
Test exhaustivo: los 16,7 M colores ida y vuelta HSV/HSL sin deriva ([[Tests]]).
