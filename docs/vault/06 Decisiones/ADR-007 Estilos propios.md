# ADR-007 Estilos propios
**Contexto**: El aspecto por defecto de WPF es anticuado.

**Decisión**: Tokens de color + estilos propios mínimos.

**Alternativas descartadas**: Tema Fluent integrado (`ThemeMode`, experimental WPF0001), librerías (MahApps, WPF-UI, MaterialDesign).

**Consecuencias**: Control total y UI neutra; más XAML propio.
