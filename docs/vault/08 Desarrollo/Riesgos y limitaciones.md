# Riesgos y limitaciones
- **HDR / pantalla completa exclusiva / DRM**: la captura puede no ser fiel o salir negra.
- **Alt+C** puede chocar con aceleradores de otras apps: es configurable y se avisa si está ocupado.
- El contenido animado queda congelado durante la captura ([[ADR-003 Captura congelada]]).
- Memoria: ~33 MB por monitor 4K durante la captura (se libera al terminar).
- El CMYK no es de impresión ([[CMYK aproximado]]).
- La escala es ajustable: las constantes están en [[Constantes]].
